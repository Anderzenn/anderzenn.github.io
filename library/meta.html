Meta Tags

HAVE to use Meta Tags
<meta charset="UTF-8"> is used to display an HTML page correctly, a web browser must know which character set to use.
Which is why we use this meta tag and set it to UTF-8.

<meta name="viewport" content="width=device-width, initial-scale=1.0, shrink-to-fit=no"> makes the website responsive.

<meta name="description" content="some content"> is used to help search engines like Google with optimizing it's results.

<meta name="keywords" content="some,content"> is used to define keywords for the website for search engines.

<meta name="author" content="your name"> sets the author of the page.

<meta name="robots" content="follow, index"> search engines read through the website and remembers it.
